# M5 — Reproducible Companion and Justified Components

> Status: pending

## Release

Publish a versioned open-source companion with reproducible setup and a tested
shared activity. Document model/media configuration, dependencies, controls,
costs, sensing/retention scope, reconnect and cancellation behavior, playback
uncertainty, and supported platforms. Separate native model capabilities from
Enthus additions. The terminal remains labeled as a legacy diagnostic.

Publish components only when M4 established independent integration value; a
PyPI library or general framework is not required. Any public API needs tested
host examples, version/compatibility rules, and traceable scenario coverage.
Python packages remain fully typed and ship `py.typed`.

Include the license, contribution guide, changelog, deterministic scenario suite,
and separately identified live/owner results with failures, baseline comparisons,
and limits. Use synthetic/redacted public fixtures. An independent setup must
reproduce the documented experience and any advertised component integration.
A local build is not publication; a scripted demo is not live perception.

## Exit criteria

- [ ] **M5-E13** (release) A versioned open-source companion release is published with
      reproducible setup artifacts; any separately published component has its own verified
      artifact.
- [ ] **M5-E14** (document) README and user documentation explain continuous presence,
      supported inputs/models, host controls, costs, capability limits, and the tested
      shared activity without claiming unimplemented behavior.
- [ ] **M5-E15** (integration) An independent setup reproduces the reference experience
      using public instructions; any advertised reusable component is also exercised through
      its supported public interface.
- [ ] **M5-E16** (document) License, contribution guide, changelog, dependency rationale,
      and compatibility policy are present; published Python interfaces are typed and ship
      py.typed.
- [ ] **M5-E17** (replay, document) Applicable scenario replays are CI-reproducible;
      live/owner findings and baseline comparisons are separately documented with failures
      and evidence limitations.
- [ ] **M5-E18** (document) Published contracts trace to exercised scenarios and M4 needs,
      with lifecycle/serialization/cancellation semantics; if no reusable API is published,
      that scope decision is explicit.
